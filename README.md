# 関数マスター道場 (Function Master Hub)

中学数学の「一次関数（変化の割合・グラフ・2点座標）」および「二次関数・放物線（三角形の面積・平行線）」をゲーム感覚で完全マスターできるWeb学習教材ポータルです。

---

## 🎯 収録アプリケーション

本ポータルサイト (`index.html`) から、以下の4つの特訓アプリにワンクリックでアクセスできます。また、各アプリ内上部のナビゲーションバーからいつでも相互に切替が可能です。

### 📊 【一次関数 特訓シリーズ ($y = ax + b$)】

1. **一次関数 マスタートレーナー (`linear.html`)**:
   - 傾き・切片・変化の割合・増加量の文章題特訓
   - 3段階難易度（標準・発展・超発展）＋ 隠しフリーザ編
   - バッジ勲章獲得システム（3連続ミスでバッジ減少のペナルティつき）
   - 復習帳機能搭載

2. **一次関数 グラフマスター (`graph.html`)**:
   - リアルタイムCanvas描画された方眼グラフから直線の式を瞬時に読み取る特訓
   - 7出題モード（標準・比例・反比例・切片と通る点・x切片とy切片・分数傾き・両切片非格子点）
   - 傾き限定フィルター（正・負・すべて）、方眼・格子点トグル、自動送り

3. **2点から直線の式マスター (`line.html`)**:
   - 2点の座標 $(x_1, y_1), (x_2, y_2)$ から直線の式を4択から選ぶスピード特訓
   - **厳選特訓問題集（全38問）** 搭載（教科書「問題14」＋ $x=\text{定数}$ 14問 ＋ $y=\text{定数}$ 14問 ＋ 直線2問）
   - 集中特訓モード: **「⚠️ x=c / y=d 特殊 (全31問)」**（$x=\text{定数}$ 16問 ＋ $y=\text{定数}$ 15問を1つのモードに統合）
   - リアルタイムCanvasグラフ図示（傾き三角形つき）＆丁寧な3ステップ解説
   - PC画面スクロール完全ゼロ（1画面収まり）設計

---

### ∪ 【二次関数・放物線 特訓シリーズ ($y = ax^2$)】

4. **放物線の公式道場 (`parabola.html`)**:
   - **モード1: 直線の式と面積**:
     - 放物線上の2点を通る直線の式 $y = a(p+q)x - apq$ と、放物線上の3点 $A(p, ap^2), B(q, aq^2), C(r, ar^2)$ が作る三角形の面積公式 $S = \frac{1}{2}|a|(q-p)(r-q)(r-p)$ を4択で答える特訓
     - 「半分 × |a| × 3つの横の差」の入試頻出・面積瞬殺テクニックを徹底演習
     - パラメータ $a, p, q, r$ を自由に入力して図と式を確認できる数値シミュレータ機能
   - **モード2: 平行な2直線とx座標**:
     - 放物線上の4点において $AB \parallel CD$ の条件を手がかりに、残り1点のx座標と共通の傾きを答える特訓
     - 「平行なら両端のx座標の和が等しい（$u+v = s+t$）」という強力な性質をマスター
   - SVGによる美しいリアルタイムグラフ描画
   - ライトモード / ダークモード切替対応

## ⚡ 共通の特徴

- **ポータルサイトから一括管理**: 全4アプリを俯瞰して選択できるランチャー画面
- **相互クイック切替バー**: 全アプリの上部ヘッダーに共通ナビゲーションを搭載
- **全画面表示対応**: ワンクリック（または `[F]` キー）で全画面表示のON/OFFを切替可能（プロジェクター投影やタブレット学習に最適）
- **Web Audio APIによる本格SE**:
  - 正解音、ファンファーレ、撃破音など効果音をブラウザ単体でリアルタイム合成（外部音声ファイル不要）
- **キーボード即答対応**: 数字キー `[1]`〜`[4]` で即回答、`[Enter]` で次の問題へ
- **美しい数式レンダリング**: KaTeX による数式表示
- **完全サーバーレス（GitHub Pages対応）**: 外部データベースやサーバー構築不要で静的ホスティング可能

## 🚀 使い方

### ローカルで実行する場合
`index.html` をブラウザ（Chrome, Edge, Safari など）で直接ダブルクリックして開くだけで、ポータル画面からすべての特訓をプレイできます。

### GitHub Pages で公開する場合
1. GitHubリポジトリの **Settings** > **Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` に設定して **Save**
3. 発行されたURL (`https://<ユーザー名>.github.io/<リポジトリ名>/`) にアクセスするだけで、スマートフォンやタブレットからもすぐにプレイできます！
