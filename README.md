# 一次関数の式 特訓アプリ (Linear Function Trainer)

中学数学の一次関数（直線の式・変化の割合・傾きと切片）をゲーム感覚でマスターできるWeb学習アプリケーションです。

---

## 🎯 アプリの特徴

- **3つの特訓モードを搭載（ワンクリックで切替可能）**:
  - **モード1: 文章題・条件特訓 (`index.html`)**:
    - 傾き・切片・変化の割合・増加量の文章題特訓
    - 3段階（標準・発展・超発展）＋ 隠しフリーザ編
    - バッジ勲章獲得システム（3連続ミスでバッジ減少のペナルティつき）
    - 復習帳機能
  - **モード2: グラフマスター (`graph.html`)**:
    - リアルタイムCanvas描画された方眼グラフから式を直接読み取る特訓
    - 7出題モード（標準・比例・反比例・切片と通る点・x切片とy切片・分数傾き・両切片非格子点）
    - 傾き限定フィルター（正・負・すべて）、方眼・格子点トグル、自動送り
  - **モード3: 2点から直線の式マスター (`line.html`)**:
    - 2点の座標 $(x_1, y_1), (x_2, y_2)$ から直線の式を4択から選ぶスピード特訓
    - **厳選特訓問題集（全38問）** 搭載（教科書「問題14」＋ $x=\text{定数}$ 14問 ＋ $y=\text{定数}$ 14問 ＋ 直線2問）
    - 集中特訓モード: **「⚠️ x=c / y=d 特殊 (全31問)」**（$x=\text{定数}$ 16問 ＋ $y=\text{定数}$ 15問を1つのモードに統合）
    - リアルタイムCanvasグラフ図示（傾き三角形つき）＆丁寧な3ステップ解説
    - PC画面スクロール完全ゼロ（1画面収まり）設計
- **全画面表示対応**: ワンクリック（または `[F]` キー）で全画面表示のON/OFFを切替可能。プロジェクター投影やタブレット・集中学習に最適
- **Web Audio APIによる本格SE**:
  - 正解音、ファンファーレ、撃破音など効果音をブラウザ単体で合成再生（外部音声ファイル不要）
- **数式レンダリング**: KaTeXによる美しい数式表示
- **GitHub Pages対応**: サーバー不要で完全動作

## 🚀 使い方

### ローカルで実行する場合
`index.html` をブラウザ（Chrome, Edge, Safari など）で直接ダブルクリックして開くだけで動作します。

### GitHub Pages で公開する場合
1. GitHubリポジトリの **Settings** > **Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` に設定して **Save**
3. 発行されたURLにアクセスするだけで、スマートフォンやタブレットからもすぐにプレイできます！
